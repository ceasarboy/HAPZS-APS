## 三、工具与用法

工具：`backend/tools/mingdao_bootstrap.py`（幂等；表单 ID 登记于 `backend/.tmp/mingdao_ids.json`，该目录已被 .gitignore 忽略）

```powershell
# backend 目录，项目内嵌 Python
$env:MINGDAO_APPKEY="<appkey>"; $env:MINGDAO_SIGN="<sign>"
python tools/mingdao_bootstrap.py --list          # 表单与行数
python tools/mingdao_bootstrap.py --create        # 创建表单（已有登记则复用）
python tools/mingdao_bootstrap.py --load          # 导入数据（行已存在则跳过）
python tools/mingdao_bootstrap.py --reload-rows   # 清空四表单行后重导
```
