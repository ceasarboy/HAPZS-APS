**项目名称**: APS-HAP 生产排产系统  
**版本**: v1.0  
**编制日期**: 2026-06-12  
**状态**: 评审中

---

## 1. 项目概述

### 1.1 项目背景

基于开源项目 OpenAPS 的约束优化引擎，与明道云 HAP 低代码平台对接，构建面向离散制造场景的**计划级自动排产系统**。系统部署于局域网，通过 React 编制界面实现人机交互，支持物料齐套、产能约束、交付进度、优先级、换线次数等多约束条件下的自动排产与生产均衡。

### 1.2 项目目标

1. 实现半天节拍（每 12 小时）的自动排产能力
2. 时间精度到小时级，覆盖 20 个项目/天、2000 台产品/天的规模
3. 通过明道云 HAP 管理基础数据（订单、物料、工艺、日历）
4. React 编制界面支持计划查看、人工调整、一键重排
5. 排产结果回写明道云，驱动下游执行

### 1.3 术语定义

| 术语 | 定义 |
|:---|:---|
| APS | Advanced Planning and Scheduling，高级计划与排程 |
| HAP | 明道云 High-productivity Application Platform |
| GOCK | OptimizationCalculusKernel，OpenAPS 闭源优化运算核 |
| MPS | Master Production Schedule，主生产计划 |
| OTD | On-Time Delivery，准时交付率 |
| OEE | Overall Equipment Effectiveness，设备综合效率 |
| ChangeOver | 换线/换模，从生产一种产品切换到另一种产品所需的时间 |
| 冻结窗口 | 已下发执行的计划时段，不允许自动重排 |


## 4. 约束模型规格

### 4.1 约束优先级与开关

| 约束 | 默认启用 | 配置项 | 说明 |
|:---|:---|:---|:---|
| 产能约束 | 是 | `enable_capacity_cons` | 各产线各时段产能上限 |
| 需求约束 | 是 | `enable_demand_cons` | 需求量满足（3 种模式可选） |
| 齐套约束 | 是 | `enable_kitting_cons` | 物料可用量限制 |
| 库存约束 | 否 | `enable_inventory_cons` | 库存容量上限 |
| 换线约束 | 是 | `enable_changeover_cons` | 换线时间惩罚 |
| 冻结窗口 | 是 | `enable_frozen_horizon` | 已下发时段锁定 |

### 4.2 目标函数权重

| 目标项 | 默认权重 | 说明 |
|:---|:---|:---|
| workload | -0 | 负号表示最大化产能利用 |
| idletime | 0 | 空闲时间 |
| job_bias | -1e-3 | 作业均衡偏置 |
| waittime | 1 | 等待时间 |
| changeover | 1 | 换线惩罚（新增） |
| load_variance | 0.5 | 负荷波动（新增，生产均衡） |

## 5. 验收标准

### 5.1 MVP 验收标准（第一阶段）

| 序号 | 验收项 | 通过条件 |
|:---|:---|:---|
| 1 | HAP 数据拉取 | 能从 HAP 读取订单、日历、工作中心数据并展示 |
| 2 | 自动排产 | 点击"排产"后 5 秒内返回结果 |
| 3 | 结果展示 | 计划矩阵正确展示各产线各时段的产品与数量 |
| 4 | 结果回写 | 排产结果成功写入 HAP 排产结果工作表 |
| 5 | 人工调整 | 可修改单元格数量并重新计算 |
| 6 | 负荷图 | 各产线负荷率柱状图正确展示 |

### 5.2 完整版验收标准（第二阶段）

| 序号 | 验收项 | 通过条件 |
|:---|:---|:---|
| 7 | 换线约束 | 排产结果中换线次数较无约束方案减少 ≥ 30% |
| 8 | 优先级 | 高优先级订单延迟率 ≤ 低优先级订单延迟率的 50% |
| 9 | 冻结窗口 | 已下发时段的计划在重排时保持不变 |
| 10 | 生产均衡 | 各产线负荷率方差较无均衡方案减少 ≥ 40% |
