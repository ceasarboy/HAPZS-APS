## 2. 核心模块职责与交互

### 2.1 数据流

```
用户操作 (React)
    │
    ├── "拉取订单" ──→ FastAPI /api/v1/hap/orders ──→ HAP Client ──→ 明道云 API
    │                                                          ←── 返回订单数据
    │                                                          ──→ Redis 缓存
    │
    ├── "开始排产" ──→ FastAPI /api/v1/schedule/create
    │                      │
    │                      ├── 创建 ScheduleTask 记录 (PostgreSQL)
    │                      ├── 发送 Celery Task (Redis Broker)
    │                      └── 返回 task_id
    │
    │   Celery Worker 异步执行:
    │                      ├── HAP Service 拉取最新数据
    │                      ├── Mapper: HAP 数据 → OpenAPS DataFrame
    │                      ├── SolverWrapper: 创建 WorkshopSolver
    │                      │       ├── create_calendar()
    │                      │       ├── create_engine()
    │                      │       ├── engine.setup()
    │                      │       ├── create_*_constraints()
    │                      │       └── engine.run()
    │                      ├── Mapper: 结果 DataFrame → HAP 字段格式
    │                      ├── HAP Service: 批量写入排产结果
    │                      └── 更新 ScheduleTask 状态
    │
    ├── "查询进度" ──→ FastAPI /api/v1/schedule/{id}/status
    │                      └── 返回 Celery 任务状态 + 进度百分比
    │
    └── "查看结果" ──→ FastAPI /api/v1/result/{id}
                           └── 返回排产结果 JSON
```

### 2.2 模块职责矩阵

| 模块 | 职责 | 关键类/函数 | 依赖 |
|:---|:---|:---|:---|
| **hap/client.py** | HAP V3 API HTTP 封装 | `HAPClient.get_rows()`, `create_rows()`, `update_rows()` | httpx, Redis |
| **hap/mapper.py** | HAP ↔ OpenAPS 数据转换 | `map_orders()`, `map_calendar()`, `map_result_to_hap()` | pandas |
| **hap/cache.py** | 选项 key 缓存、工作表结构缓存 | `OptionCache`, `StructureCache` | Redis |
| **scheduler/solver_wrapper.py** | OpenAPS 求解器封装 | `WorkshopSolverWrapper.run()` | OpenAPS, GOCK |
| **scheduler/tasks.py** | Celery 任务定义 | `solve_schedule_task()` | solver_wrapper, hap |
| **services/schedule_service.py** | 排产业务编排 | `create_schedule()`, `get_status()` | models, tasks |
| **services/hap_service.py** | HAP 数据服务 | `fetch_orders()`, `push_results()` | hap/client, hap/mapper |
| **services/result_service.py** | 结果处理 | `format_result()`, `export_csv()` | pandas |

## 3. 关键接口设计

### 3.1 排产任务 API

```
POST /api/v1/schedule/create
请求体:
{
    "time_horizon": "half_day",       # half_day | full_day | custom
    "start_time": "2026-06-13T08:00:00",
    "end_time": "2026-06-13T20:00:00",
    "constraints": {
        "enable_capacity_cons": true,
        "enable_demand_cons": true,
        "enable_kitting_cons": true,
        "enable_changeover_cons": true,
        "enable_frozen_horizon": true,
        "frozen_until": "2026-06-13T12:00:00"
    },
    "objective_weights": {
        "workload": 0,
        "idletime": 0,
        "job_bias": -0.001,
        "waittime": 1,
        "changeover": 1,
        "load_variance": 0.5
    },
    "solver_config": {
        "threads": 4,
        "time_limit": 60
    }
}

响应:
{
    "task_id": "sched-20260613-001",
    "status": "PENDING",
    "created_at": "2026-06-13T07:30:00"
}
```

## 4. 测试策略

### 4.1 测试分层

| 层级 | 测试类型 | 工具 | 覆盖范围 |
|:---|:---|:---|:---|
| **单元测试** | 后端函数/类 | pytest | HAP Client、Mapper、SolverWrapper |
| **接口测试** | API 端点 | pytest + httpx | 所有 /api/v1/* 端点 |
| **集成测试** | 端到端流程 | pytest + Celery eager | HAP→排产→回写 完整链路 |
| **前端测试** | 组件渲染 | Vitest + Testing Library | 核心组件交互 |
| **E2E 测试** | 用户操作流 | Playwright | 排产编制完整流程 |

### 4.2 关键测试用例

| 编号 | 测试场景 | 预期结果 |
|:---|:---|:---|
| T01 | HAP API 连通性 | GET /v3/app/info 返回应用信息 |
| T02 | 20 项目 × 12 时段排产 | 5 秒内返回结果，所有需求满足 |
| T03 | 换线约束生效 | 换线次数较无约束方案减少 |
| T04 | 冻结窗口 | 冻结时段计划不变 |
| T05 | 结果回写 HAP | 排产结果工作表新增记录 |
| T06 | 人工调整 + 重排 | 仅未冻结部分重排 |
| T07 | HAP 选项 key 缓存 | 二次请求命中缓存，无额外 API 调用 |
