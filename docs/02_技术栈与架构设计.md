## 4. HAP V3 API 对接规范

### 4.1 鉴权配置

```python
# backend/app/core/config.py
HAP_APP_ID = os.environ.get("HAP_APP_ID", "")
HAP_APPKEY = os.environ.get("HAP_APPKEY", "")
HAP_SIGN = os.environ.get("HAP_SIGN", "")
HAP_BASE_URL = os.environ.get("HAP_BASE_URL", "https://api.mingdao.com")

HAP_HEADERS = {
    "Content-Type": "application/json",
    "HAP-Appkey": HAP_APPKEY,
    "HAP-Sign": HAP_SIGN,
}
```

### 4.2 核心 API 调用

| 业务 | API 端点 | 方法 | 说明 |
|:---|:---|:---|:---|
| 获取应用信息 | `/v3/app/info` | GET | 验证连接 |
| 获取工作表列表 | `/v3/app/worksheets` | GET | 获取工作表 ID |
| 获取工作表结构 | `/v3/app/worksheets/{id}` | GET | 获取字段定义与选项 key |
| 查询记录 | `/v3/app/worksheets/{id}/rows/list` | POST | 带筛选、排序、分页 |
| 创建记录 | `/v3/app/worksheets/{id}/rows` | POST | triggerWorkflow: false |
| 批量创建 | `/v3/app/worksheets/{id}/rows/batch` | POST | 最多 100 条/批 |
| 更新记录 | `/v3/app/worksheets/{id}/rows/{row_id}` | PUT | 部分更新 |
| 批量更新 | `/v3/app/worksheets/{id}/rows/batch` | PUT | 最多 100 条/批 |

### 4.3 数据转换关键规则

| HAP 字段类型 | 读取处理 | 写入处理 |
|:---|:---|:---|
| SingleSelect | 返回 `[{key, value}]` | 传 `["key"]`（数组格式） |
| MultipleSelect | 返回 `[{key, value}]` | 传 `["key1", "key2"]` |
| Number | 返回字符串 `"100"` | 传数字 `100` |
| Relation | 返回 `[{sid, name}]` | 传 `["rowid"]` |
| Date | 返回 ISO 字符串 | 传 ISO 字符串 |
| Text | 返回字符串 | 传字符串 |

### 4.4 缓存策略

| 缓存项 | TTL | 说明 |
|:---|:---|:---|
| 工作表结构 + 选项 key | 1 小时 | 变更频率低 |
| 工作中心数据 | 10 分钟 | 偶有调整 |
| 生产日历 | 5 分钟 | 可能有临时变更 |
| 订单数据 | 不缓存 | 实时拉取 |
| 排产结果 | 不缓存 | 实时查询 |

## 5. 部署架构

### 5.1 Docker Compose 编排

```yaml
services:
  nginx:          # 反向代理 + 前端静态文件
    image: nginx:alpine
    ports: ["80:80"]

  fastapi:        # API 网关
    build: ./backend
    command: gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker -b 0.0.0.0:8000
    depends_on: [redis, postgres]

  celery-worker:  # 排产求解
    build: ./backend
    command: celery -A app.scheduler.celery_app worker --loglevel=info --concurrency=2
    depends_on: [redis]

  celery-beat:    # 定时任务
    build: ./backend
    command: celery -A app.scheduler.celery_app beat --loglevel=info
    depends_on: [redis]

  redis:          # 缓存 + 消息队列
    image: redis:7-alpine

  postgres:       # 生产数据库
    image: postgres:15-alpine
    volumes: ["pg_data:/var/lib/postgresql/data"]
```

### 5.2 服务器配置

| 配置项 | 最低要求 | 推荐配置 |
|:---|:---|:---|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB SSD | 100 GB SSD |
| 网络 | 局域网 + 外网 API 访问 | 同左 |

## 6. 安全设计

| 安全项 | 措施 |
|:---|:---|
| HAP 鉴权 | AppKey/Sign 仅存于后端 .env，不暴露前端 |
| API 认证 | 局域网内基础 Token 认证（JWT 可选） |
| 跨域 | Nginx 统一代理，前端同源访问 |
| 数据传输 | 局域网 HTTP；HAP API 走 HTTPS |
| 敏感配置 | .env 文件管理，不入版本控制 |
